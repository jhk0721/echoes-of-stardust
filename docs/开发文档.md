# 《星尘回响》开发文档

> 像素风叙事沙盒游戏 · 最后一位聆星者的告别之旅
> 技术栈：Python 80% + C++ 20% · 引擎：pygame 2.6 · 状态：P0/P1 骨架已跑通

---

## 0. 项目定位

**一句话**：你扮演最后一位"聆星者"，穿梭于即将消亡的记忆星球，帮记忆体完成最后执念，再弹响挽歌送他们化作星尘。

**核心玩法**：织曲战斗——四键弹奏、聆听洞察破绽、复现节奏型触发共鸣、三灵韵即兴终结技。

**美学方针**：纯黑宇宙 + 黑暗里的光。**全部素材程序化生成，零美术依赖**——这是本项目对"美工差"的根本解法（详见 §3）。

## 1. 技术架构（80/20 划分）

| 层 | 技术 | 占比 | 职责 |
|---|---|---|---|
| 引擎与游戏逻辑 | Python + pygame | 80% | 场景/UI/剧情/战斗流程/素材生成 |
| 判定核心 | C++17 共享库 (DLL) | 20% | 节拍判定、序列批量判定（性能关键路径） |
| 桥接 | ctypes（native/bridge.py） | - | DLL 缺失时自动降级纯 Python 同构实现 |

**为什么这么分**：游戏主体是叙事 + 状态机 + 程序化绘制，Python 开发效率碾压 C++；而节拍判定是每帧高频、对延迟敏感的路径，且"手感"需要反复调参，放 C++ 既快又干净。桥接层保证没有编译器也能跑。

### C++ 部分构建（可选，有编译器时）

```bash
cd native
cmake -B build
cmake --build build --config Release
copy build\Release\rhythm_core.dll .
```

构建完成后 bridge.py 自动启用 cpp 后端；没有 DLL 时运行 `python -c "from native import bridge; print(bridge.load())"` 会显示 `python`。

## 3. 素材获取策略（美工差的最优解）

**原则：程序化保底 + 免费素材增强，风格统一，零版权风险。** 管线如下：

1. **字体**：缝合像素字体 Fusion Pixel（OFL-1.1）`assets/fonts/`，10px 简体中文比例体为主，12px 等宽兜底；缺失时退回系统字体链。
2. **粒子**：Kenney Particle Pack（CC0）`assets/particles/` 透明版——星尘、flare、spark、smoke、trace、magic 全家族，主界面星尘与战斗特效全部由粒子图驱动。
3. **UI**：Kenney UI Pack Pixel Adventure（CC0）`assets/ui/` 533 项，待接入九宫格按钮/面板。
4. **音效**：Kenney UI Audio（CC0）`assets/audio/kenney/` 56 项，click/rollover 已替换程序化 UI 音。
5. **星球渲染**：GLSL 着色器（`native/planet.glsl`，参考 blackhole.glsl 的 hash 噪声 / 冷暖 tint / HDR tonemap）。运行时双轨：moderngl 真 shader 优先，无 GPU 环境自动降级纯 Python 逐像素翻译（结果一致）。统一左上光源 → 所有星球明面/暗面方向一致，秩序感强。

**素材清单（2026-08-15 已安装）**：fusion-pixel 三版字体、Kenney particle-pack / ui-pack-pixel-adventure / cursor-pixel-pack / ui-audio、OGA Platformer Art Pixel Redux + Deluxe、真实竖琴 PNG（pngimg.com harp_PNG12，409×784 透明，CC BY-NC 4.0，仅非商用；主界面已弃用，战斗场景保留）、8 张程序化专属记忆星球 PNG（`tools/gen_planets.py` 生成，`assets/sprites/planet_0~7.png`）。

**注意**：改素材后跑 `python tools/generate_assets.py` 重新生成（`ensure()` 只在缺失时生成，手动跑会全量覆盖）。新增素材直接丢进 `assets/` 对应目录，代码按路径扫描。

### 3.1 网络阻断记录（2026-08-15）

当日尝试以下素材源，全部被网络墙阻断或不可达：

| 源 | 类型 | 结果 |
|---|---|---|
| GitHub releases (fusion-pixel-font ttf) | 中文字体 | 被墙，下载超时 |
| Kenney.nl (UI Pack / Pixel Pack) | 像素素材 | 被墙，直链不可达 |
| OpenGameArt 直链 | 像素素材 | 部分可达但内容不匹配 |
| 迅雷 GUI | 下载工具 | Agent 无法可靠操作图形界面 |
| 百度网盘 (B站视频链接) | 素材包 | 需登录交互，Agent 无法完成 |
| Fontke (fontke.com) | 字体下载 | 重定向循环 / 被墙 |

**结论**：外部素材下载在沙盒网络下不可行（后经 GitHub 加速代理与 Kenney 直链手动下载成功，见下）。程序化生成保底，素材增强锦上添花。

**后续突破（同日）**：用户通过 GitHub 加速代理（gh-proxy.com）与 kenney.nl 直链成功下载全部素材包，已完成安装接入（见上方素材清单）。

**兜底**：若某天网络恢复或拿到本地素材包，Kenney / itch.io 免费包可直接丢进 `assets/`，与程序化素材混用无冲突。像素字体（如 Fusion Pixel）若拿到 ttf，替换 `config.FONT_CHAIN` 即可。

**注意**：改素材后跑 `python tools/generate_assets.py` 重新生成（`ensure()` 只在缺失时生成，手动跑会全量覆盖）。

## 4. 核心系统：织曲战斗

### 4.1 输入映射
| 按键 | 音符 | 颜色 | 效果 |
|---|---|---|---|
| J | 风 wind | 淡青 | 横向切割弧线，击退 |
| K | 火 fire | 橙红 | 火焰喷发，灼烧 |
| L | 水 water | 湛蓝 | 波浪推进，减速 |
| I | 地 earth | 赭石 | 震动波，禁锢 |
| U(按住) | 聆听 | - | 时间流速 30%，暴露敌人节奏型 |
| 空格 | 即兴终结技 | - | 需 3 灵韵 |

### 4.2 共鸣判定（判定核心在 C++）
- 每个敌人有节奏型（音符序列 + 拍间隔），如暗影兽 `风-火-风 @460ms`
- 逐拍判定：`Judge.press()` 用窗口 150ms 判断时值，窗口在 `rhythm.py` 可调
- 命中 → 伤害翻倍 + 灵韵 +1 + 共鸣音 + 闪白；错过 → 仅普通伤害
- 判定实现：`native/rhythm_core.cpp::step()`（C++）/ `bridge._py_step()`（降级），**两实现必须保持同构**

### 4.3 序列法则（finale.py）
- 相同相邻 → 同调，强度 +50%
- 相反相邻（风地/水火）→ 对位融合：蒸汽迷雾 / 沙尘暴
- 休止符后的音符 → 伤害 x2
- 8 槽填谱，5 秒作曲时间，ESC 可取消

### 4.4 敌人数据仓（扩展点）
在 `rhythm.py` 的 `ENEMIES` 里加条目即可新增敌人：

```python
"void_singer": {"name": "虚空歌者", "notes": ["water","earth","water","fire"],
                "gap_ms": 400, "hp": 90},
```

## 7. 运行方法

```bash
pip install -r requirements.txt        # 已装则跳过
python run.py                          # 首次自动生成素材 + 设置 MX150 独显
python tools/smoke_test.py             # 无头闭环自检
python tools/story_test.py             # 剧情全流程自检
```

操作：主界面 ↑↓/鼠标 选菜单，回车进入；剧情中 回车推进对话、S 跳过节点、ESC 回主界面；战斗中 J/K/L/I 弹奏，U 聆听，空格终结技，WASD 移动。
