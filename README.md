# 星尘回响 · Echoes of Stardust

> 像素风叙事 RPG · 最后一位聆星者的告别之旅
> 你穿梭于即将消亡的记忆星球，帮记忆体完成最后的执念，弹响挽歌送他们化作星尘。

宇宙是一首正在终结的乐章。你弹的不是安魂曲，是证词。

## ✨ 核心玩法

- **自由探索**：星露谷式 top-down 地图，WASD 移动，走近探索点按 E / 鼠标点击 / 数字键互动
- **织曲战斗**：J/K/L/I 四元素音符（风火水地）方向发射，精准复现敌人节奏型触发共鸣
- **即兴终结技**：三灵韵后空格填谱，8 槽五线谱自由作曲，命中**铭记旋律**触发传说级大招
- **记忆收集**：主线 / 互动 / 残片 / 聆听 四维推进，100% 后弹响终章挽歌
- **存档**：自动存档，主界面「继续聆听」续玩

## 🎮 操作

| 场景 | 操作 |
|---|---|
| 主界面 | ↑↓ 选择 · 回车确认 · F11 全屏 |
| 探索地图 | WASD 移动 · E/鼠标/数字1-6 互动 · ESC 返回 |
| 剧情 | 回车推进 · S 跳过 · ESC 返回 |
| 战斗 | WASD 移动（决定弹奏方向）· J/K/L/I 弹奏 · U 聆听 · 空格终结技 |

## 🚀 运行

```bash
pip install -r requirements.txt    # pygame 等
python run.py                      # 首次自动生成素材 + 设置 MX150 独显
```
