## 🔥 心潮澎湃的传说设定

> 这些是《星尘回响》独有的、写进代码深处的浪漫。

### 🎼 织曲战斗 · 四元素对位法则

**J 风 · K 火 · L 水 · I 地** —— 你弹的不是技能，是**乐章**。

- **同调**：相同音符相邻 → 伤害 +50%，纯粹的回响
- **对位融合**：水火相激 → **蒸汽迷雾**；风地相冲 → **沙尘暴**
- **休止·余韵**：休止符之后的音符 → 伤害 **×2**，留白的杀伤力

### ⭐ 十首铭记旋律 · 传说级大招

见证故事后，把**刻骨铭心的记忆**化作音符序列填入五线谱，即可奏响传说：

| 铭记旋律 | 效果 |
|---|---|
| **雨夜尼伯龙根** | 隐匿 15 秒 · 移动翻倍 |
| **卡西莫多的钟声** | 铜钟庇护 · 免死护盾 |
| **不要温和地走入那个良夜** | 200% 伤害 · 穿透灼烧 |
| **致绘梨衣的信** | 飘落樱花——她收到了 |
| **黑暗森林的答案** | 隐匿 5 秒 · 下一击 **×10** |
| **昂热的复仇** | 折刀形态 · 300% 伤害 |
| **未完成的诗** | 诗行版本 · 敌人自行离去 |
| **独行者的灯火** | 化身灯塔 20 秒 |
| **破镜之舞** | 镜中倒影 · 羁绊均伤 |
| **花丛中的名字** | 守护神显形 |

### 🌀 聆听 · 慢动作的破绽

按住 **U**，时间流速降到 **30%**——敌人的节奏型暴露在五线谱上，此刻你不仅是乐手，是**洞察者**。

### 🌌 记忆星球 · 消亡即挽歌

每颗星球都是一段记忆。**主线 / 互动 / 残片 / 聆听** 四维推进，集满 100% 奏响挽歌，星球化作星尘。你送别的，是每一个不肯遗忘的人。

### 🪐 16 颗星球 · 主线五章 + 自由探索

浅海星 → 暴雨孤城 → 圣母院 → 降维废墟 → 终章之路，五章主线后解锁 16 颗星球自由探索：浅草寺、卡塞尔、图书馆、数学荒原、B-612……每颗都有自己的故事与 NPC。

## ✨ 核心玩法

- **自由探索**：星露谷式 top-down 地图，WASD 移动，走近探索点按 E / 鼠标点击 / 数字键互动
- **织曲战斗**：J/K/L/I 四元素音符（风火水地）方向发射，精准复现敌人节奏型触发共鸣
- **即兴终结技**：三灵韵后空格填谱，8 槽五线谱自由作曲，命中**铭记旋律**触发传说级大招
- **记忆收集**：主线 / 互动 / 残片 / 聆听 四维推进，100% 后弹响终章挽歌
- **存档**：自动存档 + **Ctrl+S 手动存档**，主界面「继续聆听」续玩
- **全夜景化**：所有场景统一夜晚氛围，配动态星尘、流星、黑洞、五线谱
- **角色动画**：玩家 4 向走路动画、NPC 专属动作状态机（钓鱼/看报/写字/捡贝壳/触手摆动等）
- **环境音效**：风/火/水/地四键触发对应环境声（刮风/火焰/水花/落石）+ 音符反馈

## 🚀 安装与运行

**环境要求**：Windows 10/11 · Python 3.10+ · 任何显卡（无 GPU 也能跑，自动降级）

### 步骤一：安装 Python

前往 [python.org](https://www.python.org/downloads/) 下载安装 Python 3.10+，
安装时**务必勾选 "Add Python to PATH"**。

### 步骤二：下载并解压本项目

```bash
git clone https://github.com/jhk0721/echoes-of-stardust.git
cd echoes-of-stardust
```

或者点击仓库页面的绿色 **Code → Download ZIP** 解压。

### 步骤三：安装依赖

```bash
pip install -r requirements.txt    # 只需 pygame
```

### 步骤四：启动游戏

```bash
python run.py                      # 首次运行自动生成素材 + 自动设置 MX150 独显
```

或直接双击 **`启动游戏.bat`** 一键启动。

> 提示：若双击 bat 闪退，请改用上面的 `python run.py` 命令，控制台会显示错误原因。

### 素材说明

首次运行会自动生成全部音效/BGM/星球贴图（纯程序化合成，无需联网下载）。
`assets/` 下已有的 Kenney 素材包为可选增强，缺失时游戏正常运行。

## 📁 项目结构

```
core/
├── main.py            # 入口：场景管理 / 主界面 / 织曲战斗
├── config.py          # 统一配置（路径 / 颜色 / 按键 / 战斗参数）
├── scene_manager.py   # 场景栈管理（push/pop/replace/转场）
├── audio.py           # 程序化音效 + BGM + 环境音效
├── save.py            # 存档系统
├── combat/            # 节奏判定 / 灵韵 / 即兴终结技
└── story/             # 剧情场景体系
    ├── scene.py       # 对话 / 互动 / 战斗 / 挽歌
    ├── map_scene.py   # 探索地图（夜景）
    ├── walk_scene.py  # 局部场景（4向动画 + NPC 状态机）
    ├── planet_select.py # 星球选择
    ├── planet.py      # 16 星球剧情数据
    ├── ut.py          # Undertale 风格精灵适配器
    └── sd.py          # 星露谷素材适配器
tools/                 # 测试与素材生成
native/                # 星球渲染着色器
```
